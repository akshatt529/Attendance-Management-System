# Attendance Management System

# 

# A console-based attendance management application built using Java, Object-Oriented Programming (OOP), and file handling.

# 

# Features

# 

# \- Manage student records

# \- Manage subjects

# \- Record attendance for a subject

# \- Generate student-wise attendance reports

# \- Generate subject-wise attendance reports

# \- Identify students with attendance shortages

# \- Save attendance records to a file for future use

# 

# Technologies Used

# 

# \- Language: Java

# \- Concepts: Object-Oriented Programming (OOP), file handling

# \- Storage: Text file

# 

# Project Structure

# 

# \- Main.java — Application entry point

# \- AttendanceManager.java — Manages attendance operations

# \- Attendance.java — Represents attendance records

# \- Student.java — Represents student information

# \- Subject.java — Represents subjects

# \- AttendanceException.java — Handles application-specific exceptions

# 

# How to Run

# 

# 1\. Install the Java Development Kit (JDK).

# 2\. Clone or download this repository.

# 3\. Open a terminal in the project directory.

# 4\. Compile the Java source files:

# 

# &#x20;  javac \*.java

# 

# 5\. Run the application:

# 

# &#x20;  java Main

# 

# Learning Objectives

# 

# This project demonstrates the practical use of OOP principles, Java classes, exception handling, and file handling in a console-based application.
